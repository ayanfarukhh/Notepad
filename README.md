# 📝 Java Desktop Notepad

A feature-rich desktop text editor application built completely using **Java**, **Java Swing**, and **AWT**, emulating the core functionalities of the classic Windows Notepad.

---

## 🚀 Features

* **File Operations:** Create new documents (`Ctrl+N`), open existing `.txt` files using native file choosers (`Ctrl+O`), save files securely (`Ctrl+S`), and print text directly (`Ctrl+P`).
* **Advanced Text Editing:** Full support for standard text manipulation operations including **Cut**, **Copy**, **Paste**, and **Select All**.
* **Keyboard Shortcuts (Accelerators):** Quick-access keyboard shortcuts integrated for all major menu items for enhanced user productivity.
* **Custom GUI & Styling:** Built with Java Swing components, custom menu bars, scroll panes, line wrapping, and dynamic window sizing.

---

## 🛠️ Tech Stack

* **Language:** Java
* **UI Framework:** Java Swing, AWT (`JFrame`, `JTextArea`, `JMenuBar`, `JFileChooser`, etc.)
* **File Handling:** `java.io.*` (`BufferedReader`, `BufferedWriter`, `FileReader`, `FileWriter`)
* **Event Handling:** `java.awt.event.*` (`ActionListener`, Key Strokes)

## ⚙️ Setup and Installation Instructions

### Prerequisites

* **Java Development Kit (JDK)** installed on your computer.
* Any Java-compatible IDE (e.g., **IntelliJ IDEA**, **Eclipse**, or **NetBeans**).

### How to Run the Application:

1. **Clone the Repository:**

git clone [https://github.com/ayanfarukhh/Notepad.git](https://github.com/ayanfarukhh/Notepad.git)



2. **Open in IDE:**
* Import the project directory into your preferred Java IDE. Ensure the `notepad` package and resource folders are configured correctly.


3. **Run the Main Class:**
* Locate and open **`Notepad.java`**.
* Run the `main` method to launch the application window.


4. **Start Editing:**
* Create, edit, save text documents, or open existing `.txt` files seamlessly!
